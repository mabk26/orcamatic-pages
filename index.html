Smart rule engine

Form auto-submitter

Built-in task scheduler

Is ORCA just an auto-clicker?

It starts there, and then adds structure. A plain auto-clicker replays fixed coordinates and breaks when a page moves. ORCA combines a visual element picker with a rule engine, so each step stores the target element plus logic: click and retry, wait for a condition, fill a field, extract data. Multi-step workflows chain those actions across pages, pop-ups and web apps.

Does ORCA need an API key?

No. You do not need to create or paste in a third-party API key. Saved workflows and routine browser actions run locally. If you choose an AI-assisted step, ORCA handles that through its own service and your plan’s monthly AI balance.

Can it run a workflow on a schedule?

Yes. Save the workflow first, then use ORCA’s built-in task scheduler to run it on a recurring timer. It suits work such as routine checks, recurring form submissions, and data collection you would otherwise do every morning.

Will it bypass a login, CAPTCHA, or verification step?

No. ORCA is not designed to bypass security controls. If a website requires a login, a CAPTCHA, two-factor authentication, or a confirmation that needs a person, you stay in control and complete that step yourself.

Which browsers can I use?

ORCA is built for Chrome and Chromium-based browsers, including Chrome, Edge, and Brave. Install it from the Chrome Web Store to get started.
