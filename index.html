How it works

Three steps, no code. You do the task once with ORCA watching; after that, it’s one click or none.

  1. 1

    Point at it

    Turn on the picker and click the buttons, fields and data you want ORCA to use. No code, no selectors.

  2. 2

    Set the rules

    Choose what happens at each step: click, type, wait, retry, check a condition or copy the data out.

  3. 3

    Let it run

    Run it with one click, or put it on a schedule. The live log shows every step as it happens.

Questions

orcamatic@gmail.com
Do I need to know how to code?

No. You build a workflow by pointing at things on the page and choosing what should happen: click, type, wait, retry or extract. There are no scripts or selectors to write.

Does ORCA need an API key?

No. There is nothing to create or paste in. Rule-based and scheduled runs work locally in your browser. If you use an optional AI step, ORCA handles it through its own service and your plan’s monthly AI balance.

Can it run on a schedule?

Yes. Save a workflow, then use the built-in scheduler to run it at the times you choose, such as every morning, every Monday or at month-end.

Does it work on sites that have no API?

Yes. ORCA works on the page itself, inside the browser session you are already signed in to, so portals and admin tools with no integration can still be automated.

Will it get past logins or CAPTCHAs?

No. ORCA does not bypass logins, CAPTCHAs, two-factor checks or confirmations that need a person. You complete those steps yourself, and automation must stay within each site’s terms of use.

Where is my data stored?

Your workflows, rules and run logs stay in your browser’s local storage. Page content is only sent when you deliberately start an AI-assisted step. The security page lists every permission ORCA asks for and why.

Are any features locked behind a plan?

Pro ($10/year) unlocks every advanced extension feature, with no AI balance. Every AI plan includes Pro while active and adds a monthly AI balance for the Engine; AI tiers differ only in the size of that balance.

Which browsers are supported?

Chrome and other Chromium-based browsers, such as Microsoft Edge and Brave.
