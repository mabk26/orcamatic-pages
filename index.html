Questions, answered

Clear about what ORCA does — and doesn’t do.

If you need help choosing a workflow, reach us directly and we will point you in the right direction.

Email support →
Does ORCA need an API key?

No. You do not need to create or paste in a third-party API key. Saved workflows and routine browser actions work locally. If you choose an AI-assisted task, ORCA handles that through its own service and plan balance.

Can it run a workflow on a schedule?

Yes. Save the workflow first, then use ORCA’s scheduling controls to run it at a recurring time. It is useful for work such as routine checks, updates, and follow-ups.

Will it bypass a login, CAPTCHA, or verification step?

No. ORCA is not designed to bypass security controls. If a website requires a login, a CAPTCHA, two-factor authentication, or a confirmation that needs a person, you stay in control and complete that step yourself.

Which browsers can I use?

ORCA is built for Chrome and Chromium-based browsers, including Chrome, Edge, and Brave. Install it from the Chrome Web Store to get started.
