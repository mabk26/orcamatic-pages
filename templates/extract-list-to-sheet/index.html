Extract a list into a spreadsheet

For the page that already shows you a table of results: a vendor queue, a job board, a supplier catalogue, an internal case list. You tell ORCA which block repeats and which values you want; it walks the rows, writes them out, and leaves everything else alone.

The steps, written out

Build them in the ORCA panel. This is a recipe rather than a file to load: one sitting, then it is saved as your own profile.

  1. Open the list in the state you work in

    Filtered, signed in, the columns visible. Turn on the visual element picker in the ORCA panel.

  2. Mark one row, then the values inside it

    Click the row container once, then pick reference, status, date and assignee. Each is stored as a labelled target rather than a screen position, which is why it survives a redesign better than a recording would.

  3. Tell ORCA where the list ends

    Add a condition on the next-page control: keep going while it exists and is enabled, stop when it is not. Cap the row count on the first run until you trust it.

  4. Give it recovery for slow pages

    Wait for the row container to appear, allow a couple of retries. This is what stops a laggy portal from quietly producing empty rows.

  5. Run once with the log open

    Every row, retry and empty value is written to the run log, so a gap is visible instead of silent.

  6. Save the profile

    Next week it is one click, or a scheduled run if the page refreshes on its own.

What it collects. Row values you picked, read from the page you are looking at. A rule-based run like this one executes locally, so nothing leaves the browser and no AI balance is touched.
Limits worth respecting. Keep the row cap modest on lazily loaded pages, and read the site’s terms before extracting a listing at volume. This is a tool for your own work queue, not for rebuilding someone else’s database.

The arithmetic, not a promise: multiply the minutes one batch costs you by hand against the 3 batches a week you actually do. That product is what this replaces, for one sitting of about 12 min.
