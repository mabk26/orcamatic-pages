Fill a form from rows you already keep

For the re-keying job nobody wants: twenty rows in a spreadsheet that have to become twenty entries in a portal with no import button. ORCA reads the values, drives the form, and pauses wherever you tell it to wait for a person.

  • 1 batch a day
  • Runs in your browser

The steps, written out

Build them in the ORCA panel. This is a recipe rather than a file to load: one sitting, then it is saved as your own profile.

  1. Put the values where ORCA can read them

    A sheet, a CSV export, or the list view of a tool you already keep. The columns become the fields ORCA will type.

  2. Pick each control once, on the real form

    The input, the dropdown, the submit button. Pick a dropdown option as a value, so the selection matches what the site expects instead of a pixel position.

  3. Map column to field

    Reference to order number, name to claimant, note to reason. Anything you do not map stays untouched. ORCA never guesses at a field you never showed it.

  4. Gate the submit

    Submit only when the required fields are non-empty and the confirmation control is present, and retry the “button still disabled” case, which is normally a slow page rather than a broken one.

  5. Run a single row first

    Read the log, check the record inside the portal, then run the rest. One row costs ten seconds and prevents a twenty-row cleanup job.

  6. Leave the pacing on

    The built-in micro-intervals between actions keep the target site seeing human-ish timing instead of a burst of requests.

What it collects. The values you mapped, typed into the page you are on. A rule-based fill runs locally: no AI step, no upload, no balance used.
Limits worth respecting. Keep a human on the final submit for anything irreversible (payments, filings, deletions, legal acknowledgements) and do not automate a submission the site does not allow.

The arithmetic, not a promise: multiply the minutes one batch costs you by hand against the 1 batch a day you actually do. That product is what this replaces, for one sitting of about 9 min.
